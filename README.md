## 🚀 SEO & Optimization Highlights
- **SEO-Friendly Slugs**: Replaced ambiguous filenames (`service1.html`–`service6.html`) with keyword-rich URLs (`injection-molds.html`, `press-tools.html`, etc.).
- **Descriptive Image Naming**: Clean kebab-case naming for all images (e.g. `slide-1-product-design.jpeg`, `injection-mold-01.jpeg`).
- **Rich Alt Tags & Meta Tags**: High-relevance meta descriptions and title tags to improve Google indexing.
- **Unified Navigation & Lightbox**: Breadcrumb navigation bar on all subpages to allow visitors and search engines to easily discover all pages.
