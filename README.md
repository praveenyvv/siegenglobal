# Siegen Global Manufacturing Pvt Ltd

Official website repository for Siegen Global Manufacturing Pvt Ltd.

## Overview
This repository contains the static website assets and source code for Siegen Global Manufacturing Pvt Ltd, showcasing company engineering services, projects, tooling, die design, and client solutions.

## Structure
- `index.html` - Main landing page
- `projects.html` - Completed projects showcase
- `service1.html` to `service6.html` - Detailed engineering service pages
- `styles.css` - Stylesheet for layout and responsiveness
- `script.js` - Interactive functionality (navigation, slideshows, mobile menus)

## Development & Updates
To make updates and push to GitHub:
```bash
git add .
git commit -m "Update website content"
git push
```
